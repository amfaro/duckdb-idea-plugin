# agent-desktop Skill

Pi skill for using [`lahfir/agent-desktop`](https://github.com/lahfir/agent-desktop) to observe and control native desktop apps through accessibility trees.

## Installation

This repo-local skill is available from `.agents/skills/agent-desktop` once the branch is checked out.

## Use

Load when an agent needs structured desktop automation with snapshots, deterministic refs like `@e1`, and ref-based actions such as `click`, `type`, `press`, and `scroll`.
